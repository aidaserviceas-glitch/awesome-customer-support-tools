# 🤝 Contributing Guidelines

Thank you for your interest in contributing to **100 Awesome Customer Support Tools**!

This is a curated list of tools related to customer support, including chatbots, helpdesks, CRMs, live chat platforms, and more.

## ✅ How to Add a Tool

1. **Make sure the tool fits** the theme of this list — it should help improve or support customer experience, service, or engagement.

2. **Add your tool in alphabetical order** based on the tool name. The list is flat and not categorized.

3. **Use the correct format** in the table:
   ```markdown
   | [Tool Name](https://toolwebsite.com) | One-sentence description of what it does. |
   ```

4. **Keep descriptions concise and neutral** — avoid salesy language or unnecessary adjectives.

## 🚫 Submissions Will Be Rejected If:

- The tool isn’t clearly related to customer support
- The formatting doesn’t match the table
- The tool is added out of alphabetical order
- The toll is already listed
- The description is too vague or promotional
- The link is broken or leads to a non-official source

---

Thanks for helping us build a valuable resource for the support community! 🙌

Feel free to open an issue if you’re not sure whether a tool qualifies.
